# LG Remote Pro 🎮🖱️

แอปพลิเคชันรีโมทคอนโทรลอัจฉริยะสำหรับควบคุม **LG WebOS TV** ผ่านคอมพิวเตอร์ พัฒนาด้วย **Electron Framework** มาพร้อมกับหน้าจอผู้ใช้งาน (UI) ที่สวยงาม ทันสมัย และรองรับการควบคุมแบบครบวงจร ทั้งระบบเมาส์แทร็กแพด (Pointer) การสกรอลล์หน้าเว็บ ปุ่มควบคุมระบบ และปุ่มลัดเปิดเว็บไซต์แบบ Dynamic ผ่าน Cloudflare Workers

---

## ✨ คุณสมบัติเด่น (Features)

* 🔌 **Dynamic IP Connection:** รองรับการกรอกหมายเลข IP Address ของทีวีจากหน้า UI เพื่อเชื่อมต่อโดยตรงผ่าน WebSocket (Port 3001) ไม่ต้องใช้วิธีล็อกค่า IP ในโค้ด
* 🖱️ **Advanced Trackpad (image1):** พื้นที่ควบคุมพอยเตอร์เมาส์ฝั่งขวา รองรับการลากเมาส์ค้างเพื่อเลื่อนลูกศรบนทีวี และเมื่อปล่อยนิ้ว (MouseUp) จะเป็นการส่งคำสั่งคลิก (CLICK/ENTER) ทันที
* 📜 **Smooth Web Scrolling:** รองรับการรูดนิ้วหรือใช้ลูกกลิ้งเมาส์ (Wheel Event) บนแทร็กแพด เพื่อสกロールหน้าเว็บหรือบราวเซอร์บนทีวีได้ลื่นไหลเหมือนรีโมทจริง
* 🔢 **Custom Shortcut Keys (0-9):** ปุ่มลัดตัวเลข 0-9 สำหรับสั่งเปิดลิงก์เว็บไซต์ที่ตั้งค่าไว้ล่วงหน้า (เช่น Google, YouTube, Netflix หรือลิงก์รีไดเรกต์ส่วนตัว) พุ่งตรงเข้าบราวเซอร์ทีวีทันที
* 🌐 **Remote Web Launcher:** ช่องกรอกที่อยู่ URL ด้านล่างสุด สามารถพิมพ์ชื่อเว็บไซต์ใด ๆ แล้วกดปุ่ม "เปิดลิ้งค์" เพื่อสั่งให้ทีวีเปิดหน้านั้นได้ทันที
* 🎨 **Cloudflare Workers Integration:** ระบบพื้นหลังของแทร็กแพดรองรับการดึงรูปภาพแบบ Dynamic จากภายนอกผ่าน Cloudflare Workers ทำให้สามารถเปลี่ยนธีมหรือรูปภาพรีโมทจากระยะไกลได้โดยไม่ต้องคอมไพล์แอปใหม่
* 🛡️ **Content Security Policy (CSP):** ตั้งค่าระบบรักษาความปลอดภัยของ Electron อย่างรัดกุม แต่ยังคงเปิดสิทธิ์ให้ดาวน์โหลดรูปภาพจากภายนอกผ่านโปรโตคอล `https:` ได้อย่างปลอดภัย
* 📦 **Portable Build:** รองรับการแพ็กแอปพลิเคชันเป็นไฟล์ `.exe` แบบพกพา (Portable) ดับเบิลคลิกเปิดใช้งานได้ทันทีโดยไม่ต้องติดตั้งลงเครื่อง

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

```text
lg-remote/
├── main.js          # หลังบ้านควบคุม Electron (Main Process) จัดการช่องทาง IPC และ Log
├── preload.js       # ท่อเชื่อมต่อความปลอดภัย (Context Bridge) ระหว่างหน้าบ้านและหลังบ้าน
├── renderer.js      # หน้าบ้านควบคุม UI (Renderer Process) ดักจับอีเวนต์ปุ่มและเมาส์
├── index.html       # หน้าตาอินเทอร์เฟซ (UI) และการจัดสไตล์ CSS
├── remote.js        # ตัวจัดการการเชื่อมต่อ WebSocket และส่งแพ็กเกจสัญญาณไปที่ LG TV
├── package.json     # ไฟล์บันทึกข้อมูลโปรเจกต์ สคริปต์รัน/บิลด์ และ Dependencies
└── .gitignore       # ไฟล์ระบุสิทธิ์สิ่งที่ไม่ต้องการอัปโหลดขึ้น GitHub
```

## 🚀 การติดตั้งและเปิดใช้งานในโหมดพัฒนา (Installation & Development)

### 1. เตรียมความพร้อม
เครื่องคอมพิวเตอร์ของคุณต้องติดตั้ง [Node.js](https://nodejs.org/) เรียบร้อยแล้ว

### 2. ติดตั้ง Dependencies
เปิด Terminal หรือ Command Prompt ในโฟลเดอร์โปรเจกต์ แล้วรันคำสั่ง:
```bash
npm install
```

### 3. เปิดใช้งานแอปพลิเคชัน (Development Mode)
รันคำสั่งด้านล่างเพื่อเปิดหน้าต่างแอปสำหรับทดสอบ:
```bash
npm start
```

## 🛠️ วิธีการปรับแต่งฟังก์ชันใช้งาน (Customization)

### 1. การแก้ไขลิงก์ปุ่มลัดตัวเลข (0-9)
คุณสามารถแก้ไขหรือเพิ่มลิงก์ปุ่มลัดได้ในไฟล์ `renderer.js` ค้นหาตัวแปร `urlShortcutMap` แล้วปรับเปลี่ยน URL ตามต้องการ:
```javascript
const urlShortcutMap = {
  '1': 'https://google.com',
  '2': 'https://youtube.com',
  // เพิ่มเติมหรือแก้ไขตรงนี้ได้เลย
};
```

### 2. การเปลี่ยนรูปภาพพื้นหลังแทร็กแพด (Dynamic Image)
ในไฟล์ `index.html` ส่วนของ `#trackpad` ในแท็ก `<style>` คุณสามารถเปลี่ยนลิงก์ใน `url('...')` เพื่อดึงภาพจาก Cloudflare Worker หรือลิงก์รูปภาพดิบอื่น ๆ ได้:
```css
#trackpad {
    background-image: url('https://little-limit-a9f5.xxxcopyxx.workers.dev/?id=img1');
    background-size: contain;
    background-position: center;
    background-repeat: no-repeat;
}
```

## 📦 วิธีการแพ็กแอปพลิเคชันเป็นไฟล์ `.exe` (Building)

เมื่อพัฒนาและทดสอบจนเสร็จสมบูรณ์แล้ว คุณสามารถแพ็กโปรเจกต์ให้กลายเป็นโปรแกรมสำเร็จรูปในโหมด **Portable** (ไฟล์เดี่ยว ไม่ต้องติดตั้ง) ได้โดยรันคำสั่ง:

```bash
npm run dist
```

หลังจากระบบประมวลผลเสร็จสิ้น (ขึ้นคำว่า `Done`) ให้เข้าไปรับไฟล์ได้ที่โฟลเดอร์เกิดใหม่ชื่อ **`dist/`** คุณจะพบไฟล์ **`LG-Remote 1.0.0.exe`** ซึ่งสามารถก๊อบปี้ไปวางบนหน้า Desktop หรือส่งต่อให้ผู้อื่นใช้งานได้ทันทีโดยไม่ต้องเปิด Terminal อีกต่อไป
